# Неделя 2 — Алгоритмы и структуры данных

## Папки

### 📁 Encoder/
Шифрование текста разными методами

| Файл | Описание |
|------|----------|
| `Encoder.py` | Основной шифратор |
| `encoder_lang.py` | Языковой шифратор |

### 📁 text_quest/
Текстовая игра с отдельной логикой и сценарием

| Файл | Описание |
|------|----------|
| `quest_logic.py` | Логика игры |
| `quest_screenplay.py` | Сценарий |

## Отдельные скрипты

| Файл | Описание |
|------|----------|
| `Bubble Sort.py` | Сортировка пузырьком |
| `even_and_odd.py` | Поиск чётных и нечётных |
| `guess_number.py` | Игра "Угадай число" |
| `List_Deduplicator.py` | Удаление дубликатов из списка |
| `numb_stat.py` | Статистика чисел (среднее, медиана) |
| `Shopping List Tracker.py` | Трекер списка покупок |
