# Неделя 4 – Практические утилиты
Шесть проектов для автоматизации задач и работы с данными.
---
## 📁 Список проектов
| Проект                    | Описание                                   | Основные темы                              |
| ------------------------- | ------------------------------------------ | ------------------------------------------ |
| **config_manager**        | Управление конфигурационными файлами       | чтение/запись настроек                     |
| **files_organize**        | Автоматическая сортировка файлов по папкам | Работа с файловой системой, os, shutil     |
| **log_analyzer**          | Анализ и парсинг лог-файлов                | Регулярные выражения, обработка логов      |
| **phone_book**            | Телефонная книга (CRUD операции)           | Работа с файлами, список контактов         |
| **spam_filter**           | Простой фильтр спама                       | Строки, ключевые слова, проверка сообщений |
| **unique_word_generator** | Генератор уникальных слов                  | Множества, случайные слова                 |

---
